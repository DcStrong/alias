# 0001: Один Node.js сервер управляет комнатами

Status: принято

Дата: 2026-11-03

Для MVP используем Node.js HTTP, JSON-команды и SSE, без зависимостей. Сервер определяет очередь, счёт, дедлайн, карточки и права. HttpOnly cookie восстанавливает устройство при обновлении страницы; secret не входит в ссылку приглашения. Слово включается только в представление активного устройства. Версия комнаты и идентификатор карточки защищают от повторных команд.

Комнаты живут в памяти: перезапуск процесса удаляет их. Для подключения из интернета нужен доступный сервер с HTTPS и проксированием SSE без буферизации. Масштабирование на несколько процессов не поддерживается.
