# 0002: Сложность задаёт серверную колоду партии

Status: принято
Дата: 2026-11-03

На основании исследования docs/research/word-difficulty.md вводим два редакционно составленных набора: basic (по умолчанию, 661 прежнее слово) и hard (516 отдельных карточек, 262 из них многословные). Минимальные QA-пороги hard: 400 карточек и 150 словосочетаний. Брендовые карточки не копируем.

Сложность независима от режима, длительности, штрафа и кругов. Только ведущий сохраняет её в лобби; сохранение правил сбрасывает готовность. Неизвестные значения отклоняются. Для старых клиентов отсутствие поля difficulty сохраняет текущее значение; null не считается отсутствием.

На старте сервер копирует и перемешивает только выбранный набор. Выдача — существующий pop без возврата карточки. При исчерпании выбранной колоды партия завершается, подмешивания другого уровня и перетасовки использованных карточек нет. Новая игра сохраняет выбранный уровень.

В представлении комнаты difficulty — только ключ. difficulties содержит только публичные id, label, description, count; списки карточек не отправляются. Для активного устройства остаётся единственная текущая карточка. Целое словосочетание — одна карточка, оцениваемая по тем же правилам очков.

Автоматические проверки — существующий HTTP/SSE интерфейс, полный цикл и полное исчерпание обоих наборов. Редакционный QA проверяет объём, формат, отсутствие дублей/пересечений с нормализацией регистра, ё/е и пробелов. Автотесты не заменяют калибровку трудности реальной компанией. По просьбе пользователя браузерная приёмка в этой итерации оставлена ему.
