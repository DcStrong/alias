# Triage Labels

| Canonical role | Label in our tracker | Значение |
| --- | --- | --- |
| needs-triage | нужен-разбор | Требуется оценка задачи |
| needs-info | нужны-уточнения | Требуются уточнения |
| ready-for-agent | готово-для-агента | Можно выполнять агенту |
| ready-for-human | нужен-человек | Требуется участие человека |
| wontfix | не-будем-делать | Выполнение не планируется |

Метки выше — triage-роли. Жизненный цикл задачи записывается отдельно: `Progress: открыта`, `в-работе` или `выполнена`, с доказательствами проверки. Не заменяй завершение задачи triage-меткой `не-будем-делать`.
