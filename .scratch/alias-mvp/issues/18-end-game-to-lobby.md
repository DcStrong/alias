# 18: Завершить игру и вернуться в лобби той же комнаты

Status: готово-для-агента
Progress: открыта

**What to build:** ведущий завершает текущую партию без выхода участников и возвращает ту же компанию в настройки комнаты.

**Blocked by:** 13, 16.

- [ ] Отдельная команда только ведущему из handoff/playing/summary/finished; code/devices/players/команды/порядок/настройки сохраняются.
- [ ] Таймер, расписание, колода, очки, история и любые поздние/pending карточки очищаются; готовность сбрасывается, клиенты синхронизируются.
- [ ] Повтор/гонка со старой карточкой или таймером не затрагивает новую партию; в лобби действие безопасно идемпотентно.
- [ ] Можно изменить настройки и снова стартовать в той же комнате.
- [ ] В UI «Завершить игру» отличается от «Выйти» и кратко подтверждает потерю результатов.
- [ ] Содержательные HTTP/SSE тесты проверяют сохранение компании, авторизацию, остановку таймера и повторный старт.
