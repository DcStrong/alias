# 13: Однократный зачёт последнего слова после таймера

Status: готово-для-агента
Progress: открыта

**Blocked by:** None.

## Критерии приёмки

- [ ] Объясняющий может один раз зачесть именно сохранённую неразыгранную карточку после таймера; паре/команде +1, в каждый за себя объясняющему и выбранному угадавшему по +1.
- [ ] Время не продлевается, новая карточка не создаётся; текущий card endpoint после таймера остаётся недоступным, для зачёта используется отдельная серверная команда.
- [ ] Результат и счёт синхронизируются, включая уже открытые итоги последнего хода/партии; авторизация, ID карточки и версия защищают от дублей и гонок.
- [ ] Переход к следующему ходу/новой игре при незачтённой карточке должен явно закрывать окно зачёта, не молча терять возможность; при недоступном объясняющем ведущий может продолжить без очка.
