# 11: Выбор угадавшего кнопками в режиме «Каждый за себя»

Status: готово-для-агента
Progress: выполнена

**Требование пользователя:** заменить существующий выпадающий список выбора игрока кнопками с именами, сам список убрать.

**What to build:** объясняющий выбирает первого угадавшего вслух непосредственно кнопкой с именем игрока.

**Blocked by:** None.

## Контекст существующего выбора

В текущем интерфейсе список «Кто первым угадал?» выбирает winner — первого угадавшего. При подтверждении «Угадано» сервер начисляет +1 объясняющему и +1 выбранному игроку. Это не выбор следующего объясняющего или участника команды.

## Критерии приёмки

- [x] В режиме «Каждый за себя» вместо списка показаны кнопки с именами допустимых угадывающих: остальные не вышедшие игроки, без текущего объясняющего.
- [x] Выпадающий список выбора угадавшего удалён; выбранное имя явно выделяется, выбор можно изменить до подтверждения.
- [x] Назначение выбора, подтверждение «Угадано», начисление очков и серверная проверка winner остаются прежними; выбор имени сам по себе не засчитывает карточку.
- [x] Пропуск/нарушение не требуют выбирать угадавшего. Парный и командный режимы не меняются.
