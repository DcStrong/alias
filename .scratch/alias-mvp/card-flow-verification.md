# Проверка задач 10–12 и общего выпуска

Дата: 2026-11-03. Общий выпуск включает ранее готовые уровни сложности и три правки карточек. Сложный словарь не дорабатывался: задача 09 остаётся открытой.

## Поведение

- После таймера последнее показанное слово сохраняется у устройства объясняющего в итогах хода, а для последнего хода — также в итогах партии. Неразыгранное слово не раскрывается другим устройствам. Позднее угадывание сервер отклоняет, очки и длительность не меняются. При передаче следующему игроку/новой игре снимок очищается.
- После принятого «Угадано»/«Пропуск» все устройства получают только последнюю завершённую карточку в lastCompleted. Следующая активная карточка по-прежнему приватна. Нарушение не обновляет публичную карточку, отклонённые/повторные действия не раскрывают новый ответ.
- В «Каждый за себя» вместо select показаны кнопки остальных не вышедших игроков, без объясняющего. Выбранное имя выделено (aria-pressed), его можно изменить до «Угадано»; на новой карточке выбор сбрасывается. Нажатие имени само по себе не начисляет очки.

Тесты используют настоящие HTTP/SSE и управляемые часы. Ручная/браузерная приёмка по просьбе пользователя не выполнялась. Клиентский обработчик выбора дополнительно просмотрен статически; тест компонента не является доказательством ручной проверки интерфейса.
