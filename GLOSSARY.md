# Термины

- **Устройство** — браузерный клиент с секретной сессией комнаты. На нём может быть несколько игроков. Вкладки одного браузерного профиля используют одну сессию.
- **Игрок** — реальный человек с именем, очередью хода и, в режиме каждый за себя, собственным счётом.
- **Ведущий** — устройство, управляющее настройками, переходами между ходами и новой партией.
- **Объясняющий** — игрок, чей ход сейчас. Слово получает только его устройство.
- **Ход** — объяснение слов одним игроком в течение серверного таймера.
- **Круг** — по одному запланированному ходу каждого игрока исходного состава.
- **Партия** — заданное число полных кругов. Выбывшие игроки пропускают оставшиеся ходы.
- **Комната** — приватная по коду игровая сессия; код и ссылка являются приглашением, учётных записей нет.
