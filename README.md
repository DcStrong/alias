**Игра через интернет: [https://144.31.97.89](https://144.31.97.89/)**. Создайте комнату и отправьте друзьям ссылку. Развёрнуто на выделенном VPS под systemd и Nginx с доверенным HTTPS по IP. [Эксплуатация и обновление](deploy/README.md).

Исходники: [GitHub / DcStrong/alias](https://github.com/DcStrong/alias), ветка `main`. План и задачи остаются локальными Markdown-файлами в репозитории.

Русская браузерная игра для друзей: локально на одном компьютере, онлайн с нескольких или в смешанном составе. Игрок и устройство — разные сущности: добавьте всех сидящих за каждым компьютером.

## Запуск

Ветка `alias/rotating-pairs-and-corrections` добавляет режим **«Сменные пары»**, где за полный цикл каждый объясняет каждому и угадывает у каждого. Для четырёх игроков один цикл — 12 ходов; количество циклов задаётся отдельно от кругов остальных режимов. Угадывает только назначенный участник, за слово оба получают по +1, штраф относится к объясняющему. Перед стартом видны число ходов и оценка времени; роли показаны всем до начала и во время хода.

В итогах последнего хода ведущий может отменить или восстановить зачёт конкретного слова без дополнительного штрафа. Это доступно и в итогах партии до следующей игры. Исправлено исчезновение обработанного слова у ведущего при переходе в итоги и обновлении страницы. [Проверки и публикация итерации](.scratch/alias-mvp/iteration-19-21.md).

Нужен **Node.js 22+**. Установка зависимостей и сборка не требуются.

```sh
cd /Users/dc_strong/myProject/alias
npm start
```

Откройте [http://localhost:3000](http://localhost:3000). Сервер по умолчанию слушает `0.0.0.0:3000`.

Другой порт или только локальный доступ:

```sh
HOST=127.0.0.1 PORT=3001 npm start
```

Остановить: `Ctrl+C` в терминале сервера.

## Подключение друзей

- **Один компьютер:** создайте комнату, добавьте минимум двух игроков. Передавайте устройство; остальные отворачиваются перед показом карточки.
- **Одна локальная сеть:** друзья открывают `http://<локальный-IP-компьютера-с-сервером>:3000`, вводят код комнаты или переходят по ссылке с этим адресом. Разрешите входящие подключения Node.js в системном firewall, если требуется. `localhost` у друга указывает на его собственный компьютер, поэтому такую ссылку отправлять не нужно.
- **Разные сети:** нужен доступный всем постоянно работающий сервер либо уже настроенная частная сеть/VPN с маршрутом к серверу. Для интернет-размещения используйте HTTPS, один процесс Node.js и прокси с поддержкой SSE без буферизации. Текущий опубликованный сервер уже доступен по [https://144.31.97.89](https://144.31.97.89/); настраивать свой сервер для игры с друзьями не нужно.

Создавайте комнату через адрес, которым будут пользоваться друзья: тогда кнопка «Скопировать ссылку» скопирует подходящий адрес. На HTTP по IP браузер может не разрешить доступ к буферу обмена: ссылка появится в сообщении, её можно скопировать из адресной строки.

## Как играть

1. Ведущий создаёт комнату; друзья входят по ссылке или шестизначному коду.
2. Каждый добавляет имена людей за своим компьютером. Имена уникальны в комнате.
3. Ведущий сохраняет режим, время (по умолчанию 60 секунд), 1–10 полных кругов (по умолчанию 3), штраф 0 либо −1.
4. Все устройства нажимают «Мы готовы». Изменение правил/состава сбрасывает готовность. Ведущий начинает партию.
5. На экране передачи слово скрыто. Объясняющий получает устройство, остальные рядом отворачиваются; кнопка готовности одновременно показывает слово и запускает таймер.
6. Объясняйте без самого слова и однокоренных. Общайтесь вслух за столом либо в своём звонке. Спорные случаи решают участники.
7. Объясняющий нажимает «Угадано», «Пропуск» или «Нарушение». Каждый за себя: нажмите имя первого угадавшего — это сразу засчитает ответ.
8. Сервер заканчивает ход по таймеру. Объясняющий может однократно зачесть последнее слово; ведущий просматривает итоги и открывает следующий ход, при необходимости подтверждая продолжение без зачёта.
9. После последнего полного круга показан итоговый счёт. «Завершить игру» возвращает компанию в лобби той же комнаты для изменения настроек и новой партии; кнопка доступна и во время игры.

| Режим | Состав | Угаданное слово | Пропуск / нарушение при штрафе −1 |
| --- | --- | --- | --- |
| Вдвоём | Ровно 2 человека, любое число устройств | +1 паре | −1 паре |
| Каждый за себя | 2–16, в том числе 3 и нечётный состав | +1 объясняющему, +1 первому угадавшему | −1 объясняющему |
| Команды | A и B, минимум по 2 человека | +1 команде объясняющего | −1 этой команде |

Все игроки стартового состава объясняют один раз за круг. Состав во время партии не расширяется; вышедшие игроки пропускают оставшиеся ходы. При нехватке игроков партия завершается с причиной. При окончании словаря завершается досрочно; в партии не повторяются слова.

## Связь и ведущий

Обновление страницы и краткий разрыв сохраняют устройство через HttpOnly cookie и восстанавливают текущий серверный дедлайн: паузы таймера нет. Используйте ту же сессию браузера, профиль и адрес сервера. Cookie сессионная, без фиксированного суточного истечения; возврат после закрытия браузера не гарантируется. Вкладки одного профиля — одно устройство; для имитации двух устройств используйте разные браузеры/профили.

После 15 секунд отсутствия ведущего права получает подключённое устройство. Ведущий может через 15 секунд исключить отключённое устройство из лобби либо завершить отсутствующий ход. При явном выходе права передаются сразу. Если все отключились, вернитесь по исходной ссылке; первый вернувшийся получит права после периода ожидания.

## Границы MVP

Комнаты хранятся в памяти одного процесса и пропадают при его перезапуске; полностью неактивные удаляются через сутки. До 12 устройств и 16 игроков на комнату. Нет аккаунтов, встроенного голоса, автоматической проверки речи, истории прошедших партий и распределённого сервера. Код/ссылка — приглашение: делитесь только с участниками. На текущем VPS HTTPS и автопродление настроены; при переносе на другой сервер инфраструктуру потребуется настроить отдельно.

Слово получает только браузерный клиент активного объясняющего. Сидящие у этого же экрана технически используют тот же клиент: скрытие от них требует передачи устройства и соблюдения правил.
