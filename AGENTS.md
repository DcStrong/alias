# Alias: инструкции проекта

Интерфейс и пользовательские документы — на русском. Сохраняй различие игрока и устройства. Не отправляй скрытое слово другим устройствам. Не публикуй приложение без запроса.

Перед работой прочти `.scratch/alias-mvp/map.md`, спецификацию и выбранную задачу. Обновляй статус, доказательства проверки и следующий шаг после существенного изменения. Не отмечай задачу выполненной только по наличию кода.

Проверки: `npm run check`, `npm test`. Без `DATABASE_URL` игра и тесты запускаются без внешних зависимостей. Единственная зависимость — `pg` для PostgreSQL (`npm ci`); тест PostgreSQL запускается с `ALIAS_TEST_DATABASE_URL`. Не храни телефоны, почту и токены провайдеров. Не изменяй соседние проекты.
